# ITC-C508 E-Portfolio

A static GitHub Pages-ready academic e-portfolio for **Stephen Rainiel Adame** and the course **ITC-C508: Deep Learning for Predictive Modeling**.

## Pages

- `index.html` — Home and Course Expectations
- `about.html` — About Me
- `prelim.html` — Prelim Activities
- `midterm.html` — Midterm Activities
- `finals.html` — Finals Activities

## Edit the portfolio

1. Open any `.html` file in a code editor.
2. Replace bracketed placeholder text such as `[Add content here.]` with your actual course content.
3. To add screenshots, save them inside `assets/images/`, then replace a placeholder block with an image, for example:

```html
<img src="assets/images/my-activity.png" alt="Screenshot of my activity output">
```

4. Replace the student photo placeholder in `about.html` with your own image.

## Publish with GitHub Pages

1. Create a new GitHub repository, for example `itc-c508-eportfolio`.
2. Upload all files and folders from this project to the repository root.
3. In GitHub, go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub will provide the public Pages URL after deployment.

No framework or build step is required.
